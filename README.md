# OnlyPans
> A full-stack e-commerce web application for non-stick cookware.

## Tech Stack
- **Backend:** Python, Flask
- **Database:** MongoDB
- **Frontend:** HTML5, CSS3, JavaScript

## Key Features
- Dynamic product rendering directly from the MongoDB database.
- Interactive shopping cart system for users.
- Responsive UI design for smooth navigation across devices.

## How to Run Locally
1. Ensure [MongoDB](https://www.mongodb.com/try/download/community) is installed and running locally on your machine.
2. Clone this repository: 
   `git clone https://github.com/eftihia5/OnlyPans.git`
3. Install the required Python dependencies: 
   `pip install flask pymongo`
4. Start the Flask server: 
   `python app.py`
5. Open your web browser and navigate to `http://localhost:5000`
